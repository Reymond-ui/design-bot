#  Бот для управления дизайн-заявками

Telegram бот для управления заявками на дизайн в студенческом совете.

##  Функционал

### Для заказчиков:
-  Создание заявок на дизайн
-  Просмотр своих заявок
-  Удаление заявок

### Для дизайнеров:
-  Просмотр активных заявок
-  Отклик на заявки
-  Уведомления о новых заявках
